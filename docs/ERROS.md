# ERROS — Site de Portfólio devdapraia

Registro de erros encontrados durante a implementação e das soluções aplicadas.
Serve para não repetir o mesmo problema e para deixar rastro de decisões técnicas tomadas sob pressão.

**Quando registrar:** sempre que algo quebrar, se comportar de forma inesperada ou exigir uma solução não óbvia — mesmo que a correção tenha sido simples. Um registro curto agora poupa horas depois.

**Como registrar:** copie o modelo abaixo, preencha e coloque a entrada mais recente no topo da lista.

---

## Modelo de registro

```
## <data> - <título curto do erro>

- Sintoma:
- Causa:
- Solução aplicada:
- Como evitar no futuro:
```
